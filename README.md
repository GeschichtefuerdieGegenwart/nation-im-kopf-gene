# Nation im Kopf – Interaktives Lernlabor

Unterrichtsmaterial für das Wahlfach Demokratiebildung bzw. Geschichte mit Gemeinschaftskunde.

- **`index.html`**: Lernlabor „Nation im Kopf“. Es behandelt die Leitfrage „Wann bin ich Teil einer Nation – und wer entscheidet darüber?“ mit Anderson, Gellner, Hobsbawm und Smith, fünf Länderfällen, einem Kontinuum von Willens- bis Kulturnation, einer freiwilligen biografischen Reflexion und einem Abschlussurteil.
- **`gene-ohne-reisepass.html`**: Vertiefungsmodul „Gene ohne Reisepass“ zu DNA, Abstammung und Nation, mit Experimenten, Fallbeispielen und Quellen.

Die Seiten speichern keine Daten. Alle Eingaben bleiben im Browser der Nutzenden.
